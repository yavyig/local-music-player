# Local Player Offline

Public support and privacy pages for Local Player Offline 1.2 on iPhone and iPad.

- Support: https://yavyig.github.io/local-music-player/
- Privacy: https://yavyig.github.io/local-music-player/privacy/

The existing GitHub Pages site publishes the root of its main branch. These pages use static HTML and CSS; no build step is required. The app repository keeps a matching local copy under `AppStore/SupportPages`. Editing that local copy does not publish the site; deployment requires a commit to this support repository.

The version 1.2 copy covers local audio and video playback, embedded and external subtitles, movie controls, linked folders, lyrics and artwork, mixed-media playlists and ten app icons. It preserves the public contact, canonical URLs, optional HTTP transfer facts, hosting disclosure and existing no-account/no-tracking data practices. Linked originals remain with their provider; offline playback requires locally available files.
